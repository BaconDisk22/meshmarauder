# Desktop release checklist

- [ ] CI tests and Intel packaging pass on main
- [ ] Physical radio TCP handshake verified on Intel Mac
- [ ] Live packet display and demo isolation verified
- [ ] Unexpected disconnect and manual reconnect tested
- [ ] BLE and USB features accurately labeled
- [ ] Packaged runtime dependencies and GPL attribution audited
- [ ] Code signing and notarization verified when credentials are available
- [ ] DMG and ZIP tested on a clean Intel Mac
- [ ] Explicit approval received before publishing

This document does not authorize a release.
